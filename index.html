Coordinates
Every cell is editable. Each column is one characteristic: type or paste the Point number and Coordinate (X, Y, Z, TP…), Nominal, +Tol / −Tol, then one measured value per part.
Paste many points from Excel: copy your block (with or without a header row) and paste it into any Point cell — one row per point (Point · Coord · Nominal · +Tol · −Tol · values…) or one column per point both work; blank point cells take the point above.
Tolerances are always used as absolute values: LSL = Nominal − |−Tol|, USL = Nominal + |+Tol| (blue = calculated; type into LSL / USL to override). Empty −Tol = symmetric ±. For TP enter the position tolerance (⌀) in +Tol; empty TP cells are calculated as 2·√(ΔX²+ΔY²[+ΔZ²]) from the same point's coordinates. Out-of-tolerance values turn red. The table is kept in this browser until you clear it.
Supported layouts
  • Excel / CSV, one column per characteristic — header row with names, optional rows labelled LSL / USL, Min / Max, or Nominal / +Tol / −Tol; any sheet, any starting cell. Limits written in the header also work: Bore (11.98-12.02), Length 45±0.1.
  • One row per characteristic — Name, LSL, USL, values…
  • Inspection / CMM tables — columns like Feature · Nominal · +Tol · −Tol · Actual, Characteristic · Actual · Nominal · Upper Tol · Lower Tol (Calypso-style), AX · NOMINAL · +TOL · −TOL · MEAS (PC-DMIS-style), Feature · LSL · USL · Part 1 · Part 2…
  • Long format — one measurement per row: Characteristic · LSL · USL · Value.
  • Plain list of numbers — add the limits in the review step.
Scanned (image-only) PDFs have no text layer and can't be read — export the data from the measuring software instead.

How to read this report

  

    
Cp / Pp — potential capability
Tolerance width divided by 6σ. Shows what the process could achieve if it were perfectly centered.

    
Cpk / Ppk — actual capability
Distance from the mean to the nearest spec limit, divided by 3σ. Cpk uses short-term (within) variation; Ppk uses long-term (overall) variation.

    
Status
Capable: index ≥ target. Marginal: 1.00 ≤ index < target. Not capable: index < 1.00 (process spread exceeds the tolerance).

    
σ within / σ overall
Within: average moving range ÷ 1.128 (subgroup size 1) or R̄ ÷ d₂ (subgroups). Overall: sample standard deviation of all values.

    
Expected PPM
Parts per million expected outside the limits, from a normal fit with σ overall.

    
Control chart rules
Red points: beyond the 3σ control limits, a run of 8 on one side of the center line, or 6 steadily rising/falling.

    
Normality p
Anderson–Darling test; p < 0.05 means the data are probably not normal and normal-based indices may be misleading.

    
95% lower bound
One-sided confidence bound on the index (Bissell). Small samples give wide uncertainty.

    
Recommendations
Generic engineering guidance computed from the data — verify against your process knowledge.
